# dslr (data science: logistic regression)
42's logistic regression task (see also: [ft\_linear\_regression](https://github.com/DISN-kolo/ft_linear_regression))

## Objective
Given a dataset of various students in a fictional campus, determine some stats, do some displays, calculate some dependencies

## Installing
1. `python -m venv venv` for the first run
2. both then and in every subsequent run `source venv/bin/activate`
3. if this is the first run, `pip install -r requirements.txt`
4. done working? `deactivate`
