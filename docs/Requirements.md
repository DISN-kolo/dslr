## Objectives
This project will only cover some basic of data exploration before sending it to the machine learning algorithm. 

An implementation of a linear classification model as a continuation of [linear regression](https://github.com/DISN-kolo/ft_linear_regression): a *logistic regression*. Its encourage to build a *machine learning* toolkit.
#### Summarized
- Learn how to read a data set, visualize it in different ways, and select and clean unnecessary information from your data.
- Train a  logistic regression model that will solve a classification problem.

## General Instructions
Although any programming language is available to use, we went with python. The [R programming language](https://www.r-project.org/) is also a strong contender for this project since most of its best qualities are already integrated to it.

At the same time, the use of any method that performs all the heavy lifting for the project (e.x.: the describe() method from pandas DataFrame) is considered cheating, as this is a project oriented to learning.

### Part 1: Data Analysis
>  Each dataset and problem has to be approached in a unique way. Other way to analyze the data will surely appear in the future.

The first step is to look a the available data. Look at what format is presented in, whether there are various types of data, the different ranges, and so on. It is important to make an idea of the raw materials given before starting. The more someone works with data, the more they will develop and intuition about how you will be able to use it.

For this part, *Professor McGonagall* asks to produce a program called describe.py. This program will take a dataset as a parameter. All it has to do is display information for all numerical features.
